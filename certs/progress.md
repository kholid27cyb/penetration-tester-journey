# Progres Sertifikasi

| CompTIA Security+ atau CC (ISC2) | Bulan 3–4 | ⬜ Opsional | Dasar umum |
| eJPT | Bulan 10–11 | ⬜ | Praktik, tingkat pemula |
| PNPT atau CPTS | Bulan 16–18 | ⬜ | |
| OSCP | Setelah bulan 18 | ⬜ | Target lanjutan |
