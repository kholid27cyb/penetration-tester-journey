# Bulan 1 — Setup dan Linux

**Target akhir:** nyaman memakai terminal, paham permission dan proses, punya 4–5 artikel dan 1–2 skrip di GitHub.
Nama room dan level bisa berubah, sesuaikan dengan yang tersedia.

## Minggu 1 — Setup dan orientasi
- [ ] **Senin (1,5 jam):** buat akun TryHackMe, GitHub, Notion. Siapkan Learning Log.
- [ ] **Selasa (1,5 jam):** TryHackMe Pre Security: pengantar cyber security dan cara memakai lab.
- [ ] **Rabu (1,5 jam):** Linux Fundamentals Part 1 (ls, cd, cat, find, grep). Praktik di terminal Ubuntu sendiri.
- [ ] **Kamis (1 jam):** skill drill pertama: tulis 20 perintah Linux dari ingatan, lalu cocokkan.
- [ ] **Jumat (1 jam):** OverTheWire Bandit level 0–5. Rapikan catatan.
- [ ] **Sabtu (2 jam):** artikel pertama: perkenalan dan rencana belajarmu.

## Minggu 2 — Linux lanjut
- [ ] **Senin:** Linux Fundamentals Part 2 (SSH, flag, pipe, redirect).
- [ ] **Selasa:** Linux Fundamentals Part 3 (editor teks, proses, cron, paket, log).
- [ ] **Rabu:** permission dan kepemilikan (chmod, chown, sudo). Buat folder latihan.
- [ ] **Kamis:** skill drill topik Minggu 1.
- [ ] **Jumat:** OverTheWire Bandit level 6–12.
- [ ] **Sabtu:** artikel cheat sheet Linux untuk pemula pentest.

## Minggu 3 — Bash, proses, log
- [ ] **Senin:** dasar Bash scripting (variabel, if, loop).
- [ ] **Selasa:** tulis skrip kecil (misalnya menghitung baris tertentu dari `journalctl`).
- [ ] **Rabu:** proses dan service (`ps`, `top`, `systemctl`, `journalctl`).
- [ ] **Kamis:** skill drill topik Minggu 2 dan Minggu 1.
- [ ] **Jumat:** OverTheWire Bandit level 13–20.
- [ ] **Sabtu:** artikel tentang skrip Bash pertamamu.

## Minggu 4 — Konsolidasi
- [ ] **Senin:** tinjau catatan Bulan 1, tandai topik lemah di [skill checklist](../skill-checklist.md).
- [ ] **Selasa:** ulangi lab yang gagal atau tertinggal.
- [ ] **Rabu:** **mini project** — skrip Bash yang merangkum jumlah login gagal dari log sistem.
- [ ] **Kamis:** skill drill penuh 30 menit tanpa catatan.
- [ ] **Jumat:** push skrip ke GitHub, cek `df -h /`, bersihkan disk bila perlu.
- [ ] **Sabtu:** artikel ringkasan Bulan 1: apa yang berhasil, apa yang sulit, rencana Bulan 2.
